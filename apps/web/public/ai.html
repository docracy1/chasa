Copy this URL into your AI assistant’s connector settings (see the setup steps below) — it’s a server address for your assistant to call, not a page to open in your browser, so visiting it directly won’t show anything useful. Nothing is ever emailed or changed through MCP — every tool here is draft-only / read-only.

IDE / agent clients — configs

Formats differ by client. Cursor and Claude Code use an mcpServers JSON file; ChatGPT and Grok take the server URL in their connector UI (same endpoint as above).

Cursor / Claude Code mcpServers JSON

Add this to your client’s MCP config file (Cursor’s .cursor/mcp.json, Claude Code’s .mcp.json): 

{
{
  "mcpServers": {
    "chasa": {
      "url": "https://api.chasa.io/mcp"
    }
  }
}

Some clients want a "type": "http" field alongside "url" — check your client’s MCP docs if this doesn’t connect right away.

ChatGPT connector URL

ChatGPT does not use mcpServers JSON. Enable Developer Mode (Settings → Security and login), then Settings → Connectors (or Plugins) → Add custom connector and paste: 

https://api.chasa.io/mcp

Authentication: None. In a chat, pick Chasa from the Tools menu (or type “@Chasa”).

Grok connector URL

Grok’s chat UI is URL-based (not mcpServers JSON). On a paid tier: click “+” in the chat box → Connectors → New Connector → Custom, or open grok.com/connectors, and paste: 

https://api.chasa.io/mcp

Once added, ask normally — Grok calls the tool when it’s relevant. Grok’s CLI / agent tooling can also reuse the Cursor mcpServers JSON above (or a ~/.grok/config.toml entry with the same URL).
