Chasa documentation

Quick reference for getting started, connecting your accounting tools, and using the Zapier API.

Getting started

  1. Open the Chasa tool — no signup required for the free tier.
  2. Add invoices manually (client, amount, due date) or upload a CSV export from your accounting software.
  3. Click Draft chase to generate a tone-matched follow-up email.
  4. Copy the draft into your email client or open the mailto link. Chasa never sends on your behalf.
  5. Mark the invoice done when paid, or schedule your next reminder.

Free tier includes 5 AI drafts per month. Sign in to upgrade to Solo ($7/mo) or Pro ($17/mo) for unlimited drafts, tone tweaks, and connectors.

Connectors overview

Chasa supports several ways to get overdue invoices into the tool:

  • CSV upload (Free) — export from QuickBooks, Xero, FreshBooks, Wave, Zoho, sevDesk, or any spreadsheet. Chasa maps common column headers automatically.
  • QuickBooks Online (Solo+) — native OAuth in Connector. Imports overdue invoices into your aging board.
  • Xero (Solo+) — same OAuth flow as QuickBooks.
  • Cloud storage (Solo+) — Dropbox, OneDrive, or Box PDF import. The worker extracts client, amount, and due date hints from invoice PDFs.
  • Zapier / Make (Solo+) — push invoices via API key (see below).

Zapier API key

On Solo or Pro, create an API key in Webhooks & API under your account settings. Use it to send invoice data from Zapier, Make, or custom scripts.

Endpoint: POST https://api.chasa.io/api/invoices/import

Headers:

  • Authorization: Bearer YOUR_API_KEY
  • Content-Type: application/json

Body example:

{
  "invoices": [
    {
      "client": "Acme Corp",
      "amount": 2400.00,
      "currency": "USD",
      "dueDate": "2026-06-15",
      "invoiceNumber": "INV-1042"
    }
  ]
}

Imported invoices appear in your aging board. Draft chases from there as usual. Rate limits apply per plan — see account settings for details.
